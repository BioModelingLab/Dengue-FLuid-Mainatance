# Dengue-FLuid-Mainatance
Optimal Fluid Maintanance in Clinical Dengue Patients
The following MATLAB scripts and functions were developed for the numerical simulations and analysis of Dengue-Fluid-Maintanance Project.

Fitting_dengue_liquid.m performs model fitting and generates the profile likelihood plots. Before running this script, download the functions MiniFisher.m, ProfLike.m, and seiqrCost.m from the following GitHub repository: param-estimation-SIR
cmnd_ctrl.m and cmnd_ctrl_delay perform optimal control simulations and simulations related to delayed infusion.
