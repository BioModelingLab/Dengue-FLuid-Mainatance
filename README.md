# Dengue-FLuid-Mainatance
Optimal Fluid Maintanance in Clinical Dengue Patients
The following MATLAB scripts and functions were developed for the numerical simulations and analysis of Dengue-Fluid-Maintanance Project "A Theoretical Model for Optimal Fluid Maintenance in Clinical Dengue Patients".

Fitting_dengue_liquid.m performs model fitting and generates the profile likelihood plots. Before running this script, download the functions MiniFisher.m, ProfLike.m, and seiqrCost.m from the following GitHub repository: https://github.com/epimath/param-estimation-SIR

cmnd_ctrl.m, cmnd_ctrl_delay, and cmnd_ctrl_eta_dP.m perform optimal control simulations and simulations related to delayed infusion. M-files with _c naming are associated with optimal control simulations.
